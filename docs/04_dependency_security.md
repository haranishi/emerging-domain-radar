# 依存関係の更新（Next.js 16.4.2）

実施: 2026-10-22 JST。ユーザーが「公開しているもののうち、脆弱性があるものを更新したい」と依頼し、更新の範囲として公開リポジトリ7本を選択。

## 背景と要件

- Next.js 16.3.4 に、既知の脆弱性が 7 件あった（GitHub 公式の脆弱性データベースで重大 1・高 1・中 4・低 1）。
- ローカル専用のWebアプリ（公開先なし）。複製して使う人が古い版を入れないよう更新する。
- 要件: Next.js を 16.4.2（既知の脆弱性 0 件）にする。本番側（実行時）の依存の既知の脆弱性を 0 件にする。ソース・画面・テストは変えず、更新前から成功していた検証は更新後も成功させる。

## 更新した依存

`eslint-config-next` は上げていない（lint の検出が変わるおそれがあり、今回の目的に不要）。

- lint: エラー0・警告1（更新前と同じ）

- テスト: 399件成功・2件失敗（更新前後で同じ。公開リポジトリに `.env.example` が無いための既存の失敗）

- 依存の再照合（OSV.dev）: 本番側（実行時）の指摘 0 件。残りは開発用ツールの 5 パッケージのみ。
